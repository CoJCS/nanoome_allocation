# 이분 그래프 배정 문제와 헝가리안 알고리즘

---

## 1. 들어가며 — 왜 이런 수학이 필요한가?

학급 프로그램 배정처럼 **"사람을 자리에 1:1로 배치하되, 전체적으로 가장 만족스럽게"** 하는 문제는 일상에서 자주 나옵니다.

- 20명의 봉사자 → 5개 공부법 프로그램(각 4명)
- 각 사람은 1지망, 2지망, 3지망을 적어 둠
- **규칙:** 한 사람은 정확히 한 프로그램, 한 프로그램 정원은 정확히 4명
- **목표:** 가능한 한 많은 사람이 높은 순위의 프로그램에 배정되도록

이 문제를 수학적으로 정리한 것이 **이분 그래프 배정 문제**이고,  
그것을 효율적으로 푸는 대표적인 방법이 **헝가리안 알고리즘**입니다.

---

## 2. 그래프로 생각하기

### 2.1 그래프란?

**그래프**는 **점(정점)** 과 **점을 잇는 선(간선)** 으로 이루어진 구조입니다.

```
  A ●─────● 1번 자리
    │
  B ●─────● 2번 자리
    │
  C ●─────● 3번 자리
```

- 왼쪽 점: 사람 (A, B, C)
- 오른쪽 점: 자리 (1번, 2번, 3번)
- 선: "이 사람을 이 자리에 배정할 수 있다"는 가능성

### 2.2 이분 그래프(Bipartite Graph)란?

정점을 **두 그룹**으로 나누고, **같은 그룹끼리는 연결하지 않는** 그래프입니다.

```
  [사람 그룹]          [자리 그룹]

   김명진 ●───────────● Korean-1
   김서연 ●───┐       ● Korean-2
   천정민 ●───┼───────● Korean-3
            └───────● Korean-4
   ...
```

- 왼쪽: 봉사자 20명
- 오른쪽: 프로그램 슬롯 20개 (Korean 4개 + Math 4개 + …)
- **이분(Bipartite)** = "두 갈래로 나뉜" 그래프

### 2.3 매칭(Matching)이란?

**매칭**은 간선을 골라서, **각 정점에 연결된 간선이 최대 1개**가 되도록 하는 것입니다.

- 한 사람 → 최대 1개 슬롯
- 한 슬롯 → 최대 1명

20명과 20슬롯이 모두 짝을 이루면 **완벽 매칭(Perfect Matching)** 이라고 부릅니다.

## 3. 배정 문제(Assignment Problem)란?

### 3.1 문제 설정

- 사람 \(n\)명, 일(슬롯) \(n\)개
- 사람 \(i\)를 일 \(j\)에 배정하면 **비용(불만족)** \(c_{ij}\)가 듦
- **각 사람은 정확히 1개 일**, **각 일은 정확히 1명**에게 배정

**목표:** 총 비용을 **최소화**

\[
\text{최소화} \quad c_{1,j_1} + c_{2,j_2} + \cdots + c_{n,j_n}
\]

여기서 \(j_1, j_2, \ldots, j_n\)은 서로 다른 일 번호입니다 (중복 배정 불가).

### 3.2 비용 행렬(Cost Matrix)

위 내용을 표(행렬)로 정리하면 **비용 행렬** \(C\)가 됩니다.

**행** = 사람, **열** = 슬롯, **칸의 숫자** = 그 배정의 비용

|  | Korean-1 | Korean-2 | Math-1 | … |
|--|:--------:|:--------:|:------:|---|
| 김명진 | **0** | **0** | 10 | … |
| 박석진 | 10 | 10 | **0** | … |
| … | … | … | … | … |

- **0** = 1지망 (가장 좋음)
- **1** = 2지망
- **2** = 3지망
- **10** = 선호 목록에 없음 (매우 싫음)

숫자가 **작을수록** 좋은 배정입니다.

### 3.3 선형 합 할당 문제 (LSAP)

위와 같이 "행·열을 1:1로 짝지어 **비용의 합**을 최소화"하는 문제를  
**선형 합 할당 문제(Linear Sum Assignment Problem, LSAP)** 라고 부릅니다.

- **선형:** 각 배정 비용을 그냥 더함 (비용 × 배정 여부)
- **할당:** 1:1 배정
- **합:** 더해서 최소화

## 4. 작은 예제로 이해하기

### 4.1 사람 3명, 프로그램 3개

|  | A | B | C |
|--|:-:|:-:|:-:|
| 1번 | 0 | 1 | 10 |
| 2번 | 1 | 0 | 2 |
| 3번 | 10 | 2 | 0 |

- 1번 → A (비용 0)
- 2번 → B (비용 0)
- 3번 → C (비용 0)

**총 비용 = 0** (모두 1지망)

### 4.2 경쟁이 있는 경우

|  | A | B | C |
|--|:-:|:-:|:-:|
| 1번 | 0 | 1 | 10 |
| 2번 | 0 | 1 | 10 |
| 3번 | 1 | 0 | 2 |

A는 1번·2번 둘 다 1지망 → **1명만** A에 갈 수 있음.

**최적 배정:**
- 1번 → A (0)
- 2번 → B (1)
- 3번 → C (0)

**총 비용 = 1**

2번을 A에 억지로 넣으면 1번이 밀려서 총 비용이 더 커질 수 있습니다.  
**전체 합이 최소**인 배정을 찾는 것이 핵심입니다.

## 5. 정원이 여러 명인 프로그램 — 슬롯 복제

공부법은 Korean, Math, English, Science, Social **5과목 × 4명 = 20슬롯**입니다.

같은 과목 슬롯 4개는 **서로 바꿔도 동일**합니다.  
(Korean-1이든 Korean-4이든, Korean에 배정되면 비용은 같음)

그래서 프로그램을 **정원만큼 복제**합니다.

```
Korean  → Korean, Korean, Korean, Korean  (4슬롯)
Math    → Math, Math, Math, Math            (4슬롯)
...
```

이렇게 하면 "Korean 4명"이라는 조건을 **20×20의 1:1 배정 문제**로 바꿀 수 있습니다.

## 6. 헝가리안 알고리즘 (Hungarian Algorithm)

### 6.1 이름의 유래

1955년 헝가리 수학자 **Harold Kuhn**이 정리한 방법입니다.  
(이후 Munkres 등이 보완하여 "Kuhn–Munkres 알고리즘"이라고도 부릅니다.)

### 6.2 알고리즘이 하는 일 (직관)

**입력:** \(n \times n\) 비용 행렬  
**출력:** 총 비용이 **가장 작은** 1:1 배정

**핵심 성질:**  
\(n\)이 수백·수천이어도 **항상 전역 최적해(가장 좋은 답)** 를 찾을 수 있고,  
시간 복잡도는 대략 **\(O(n^3)\)** 입니다.

- \(n = 20\) → 순식간
- \(n = 1{,}000\) → 여전히 실용적

### 6.3 왜 "그냥 각자 1지망 고르기"로는 안 되나?

각자 1지망만 따르면:

- English 1지망 5명 vs 정원 4 → **1명은 반드시 실패**
- 누가 밀릴지, 밀린 사람을 어디로 보낼지 **연쇄적으로** 정해야 함

헝가리안 알고리즘은 **모든 사람·모든 슬롯 조합**을 고려하여  
**총 비용이 최소**가 되도록 한 번에 결정합니다.

### 6.4 알고리즘의 큰 흐름 (개념 수준)

고등학교 수준에서는 세부 단계까지 외울 필요는 없습니다.  
큰 그림만 이해하면 충분합니다.

1. **비용 행렬**을 준비한다.
2. 행·열에 적당한 수를 더하거나 빼 **등가 변환**을 한다  
   (최적해가 바뀌지 않도록 조정).
3. **0원짜리 배정**을 최대한 많이 찾는 **완벽 매칭**을 만든다.
4. 매칭이 \(n\)개 미만이면, 행렬을 조정하고 3번을 반복한다.
5. \(n\)개의 1:1 배정이 완성되면 종료 — 이것이 **최적해**이다.

실제 구현에서는 SciPy의 `linear_sum_assignment` 같은 검증된 라이브러리를 사용합니다.

```python
from scipy.optimize import linear_sum_assignment

row_ind, col_ind = linear_sum_assignment(cost)
# row_ind[i]번 사람 → col_ind[i]번 슬롯
```

## 7. Nanum Class 프로젝트에의 적용

### 7.1 비용 함수

```python
def _preference_cost(rank: int) -> int:
    return {1: 0, 2: 1, 3: 2}.get(rank, 10)
```

| 선호 순위 | 비용 |
|----------|------|
| 1지망 | 0 |
| 2지망 | 1 |
| 3지망 | 2 |
| 미기재 | 10 |

### 7.2 공부법(Study) 배정 흐름

```
[입력 CSV]  →  [20×20 비용 행렬 생성]  →  [헝가리안 알고리즘]
                                              ↓
                                        [최적 배정 결과]
```

- Study, Career, Other는 **각각 독립**으로 LSAP를 풉니다.
- 공부법만 입력해도 Career/Other가 비어 있어도 Study 결과는 동일합니다.

### 7.3 시뮬레이션에서 본 현상

**상황:** English 1지망 5명, 정원 4

| 시나리오 | 최제찬 2지망 | 총 비용 | 1지망 충족 |
|---------|-------------|--------|-----------|
| A | Social | **1** | 19/20 |
| B | Korean | **2** | 18/20 |

- Social에 1지망 3명, 정원 4 → **여유 1자리**
- 시나리오 A: 최제찬이 Social(2지망)으로 흡수 → 총 비용 1
- 시나리오 B: Social이 2지망에서 빠짐(비용 10) → 연쇄 재배정 → 총 비용 2

**교훈:** 2지망은 단순한 "예비 선택"이 아니라,  
알고리즘이 **저비용 대안 경로**로 사용하는 전략적 정보입니다.

## 8. 자주 쓰는 용어 정리

| 용어 | 쉬운 설명 |
|------|----------|
| **이분 그래프** | 정점을 두 그룹으로 나눈 그래프 (사람 \| 자리) |
| **매칭** | 각 정점에 간선이 최대 1개인 간선 집합 |
| **완벽 매칭** | 모든 정점이 짝을 이룬 매칭 |
| **비용 행렬** | 사람×슬롯 배정 비용을 표로 정리한 것 |
| **LSAP** | 1:1 배정으로 비용 합을 최소화하는 문제 |
| **헝가리안 알고리즘** | LSAP의 최적해를 찾는 고전 알고리즘 |
| **전역 최적해** | 모든 가능한 배정 중 **가장 좋은** 해 |
| **슬롯 복제** | 정원 \(k\)인 프로그램을 \(k\)개의 동일 슬롯으로 표현 |

## 10. 요약

1. **이분 그래프 배정 문제**  
   - 사람과 자리를 두 그룹으로 두고, 1:1로 짝 짓되 **총 불만족(비용)을 최소화**하는 문제

2. **비용 행렬**  
   - 선호 순위를 숫자(0, 1, 2, 10)로 바꾼 표

3. **헝가리안 알고리즘**  
   - 이 문제의 **최적해를 보장**하는 효율적인 풀이  
   - "각자 1지망만"보다 **전체적으로 더 나은** 배정을 찾음

4. **Nanum Class**  
   - 20명 → 20슬롯 LSAP를 카테고리별로 적용  
   - 공부법 시뮬레이션은 English 정원 경쟁과 2지망의 역할을 보여 주는 좋은 사례
